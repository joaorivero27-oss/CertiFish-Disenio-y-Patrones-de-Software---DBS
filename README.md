# CertiFish · Diseño y Patrones de Software

Proyecto grupal del curso 1ASI0771 (UPC, ciclo 2026-2) de la startup **Deep Blue Solutions**.

CertiFish es una plataforma de trazabilidad para la pesca artesanal peruana: registra y verifica las capturas, consolida lotes y emite certificados verificables públicamente para la exportación (CATCH y SIMP).

## Contenido
- [`Test-Use-Cases/`](Test-Use-Cases): Test Use Cases en Cucumber de las 16 Historias de Usuario (sección 17 del informe). Instrucciones en su README.
